## Ушаков Максим Викторович, тестовое задание "сервер и клиент UDP"

### Особенности реализации

1. ProgramParameters - парсер параметров командной строки.
2. SocketHolder - обёртка над сокетами, чтобы не забывать.
3. MessagesManager - менеджер вывода в сервере, чтобы правильно слать вывод для консольного или демонизированного варианта.
4. Демонизация сделана "классическая". Сейчас рекомендуется делать "new style daemonization", но я не стал усложнять.
5. Формат общения: клиент шлёт пакет, сервер его принимает, отправляет новое значение счётчика пакетов.
6. Клиент при завершении работы выводит последнее полученное значение счётчика сервера.

### Сборка

Есть Makefile, сборка, соответственно:

- Сервер: make server
- Клиент: make client

### Запуск сервера

Например, для демонизированного варианта:

> ./server --log server_log.txt --port 1234 --daemon

### Запуск клиента

Например, если на той же машине:

> ./client --count 100 --interval 10 --host 127.0.0.1 --port 1234
